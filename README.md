A fridge works the night shift alone, and it notices things. The sushi somebody brought home on Monday and forgot about has been sitting in the back for days now, long enough to get organised. The program writes the fridge's one 3am text about it to the output file, checks it fits the 140 character limit first, and that is the entire entry.

## Run it

```sh
node main.ts
```
